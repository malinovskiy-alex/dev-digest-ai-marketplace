Getting started

From zero to your first plugin in Claude Code, then a shared setup for your team.

1. What is a plugin marketplace?

A marketplace is a Git repository that lists Claude Code plugins. You add it once, then install any plugin from it by name. A plugin bundles one or more of these:

SKILL
Instructions Claude loads when your request matches their description.
AGENT
A subagent with its own prompt and tools that Claude can delegate to.
HOOK
A command that runs automatically on a Claude Code event, such as after a tool call.
MCP
A server that gives Claude new tools, locally or over the network.
