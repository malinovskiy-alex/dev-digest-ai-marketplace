# example-plugin

Summarizes articles, changelogs or notes into a short developer digest.

## Install

```
/plugin marketplace add malinovskiy-alex/dev-digest-ai-marketplace
/plugin install example-plugin@dev-digest-ai
```

## Components

| Type  | Name                        | Description                     |
|-------|-----------------------------|---------------------------------|
| Skill | `/example-plugin:summarize` | Summarize content into a digest |

## Hooks, network calls, telemetry

None.
