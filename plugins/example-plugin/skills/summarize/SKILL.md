# Summarize

Turn the provided content into a concise developer digest:

1. Start with a one-sentence TL;DR.
2. List 3–7 key points as bullets, most important first.
3. Call out breaking changes, deprecations or required actions separately.
4. Keep technical terms and code identifiers exact; do not invent details.
